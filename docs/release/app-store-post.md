# VerbNest: App Store listing copy

**Name:** VerbNest
**Subtitle:** Local-first API client

## Promotional text
Send requests, write tests and keep every collection on your own machine. No account, no cloud, no sync service.

## Description
VerbNest is a fast API client for developers who want their work to stay on their own computer. Your collections, environments and history live in a local workspace. There is nothing to sign in to.

**Build and send requests.** Every HTTP method, query params, headers, JSON, form, multipart and binary bodies, and GraphQL. Variables like `{{baseUrl}}` resolve from globals, environments, collections and folders. Secret values stay on your device.

**Organise your work.** Collections, folders and tabs. Favourites, workspace search and a command palette (Cmd+K) take you to any request fast. Save responses as examples and browse them later.

**Inherit auth.** Set Basic, Bearer, API key or OAuth once on a collection or folder. Requests inherit it.

**Script and test.** Write pre-request and post-response scripts in JavaScript with a Postman-compatible `pm` API, syntax highlighting and completion. Add no-code assertions on status, headers, body and time, and see pass or fail in the Tests tab.

**Run collections.** The runner executes a folder or whole collection with a chosen environment and shows results per request.

**Inspect everything.** Pretty and raw response views, folding JSON, headers, cookies, the exact request sent, a history of past calls and a network console.

**Generate code.** Turn any request into cURL and other snippets. Secrets are masked unless you choose to fill them in.

**Bring your work in and out.** Import Postman collections, environments and examples, cURL commands, OpenAPI and HAR. Export a readable workspace snapshot of plain files you can keep in Git.

**Built for real networks.** Proxy, custom CA certificates, client certificates and a cookie jar.

**Made for everyone.** Light and dark themes, keyboard shortcuts, and English and Arabic, including right-to-left layout.
