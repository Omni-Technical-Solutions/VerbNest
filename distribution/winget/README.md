# winget

Templates for a `microsoft/winget-pkgs` pull request. Fill in the real installer URL and SHA-256 after an installer (MSIX or Inno Setup) has been built and signed; none exists yet.

Package identifier: `Verbnest.Verbnest`. Use `wingetcreate` to generate the three manifests (version, installer, locale) from the installer URL, then add the description and tags from `docs/release/store-listing.md`.
